Nesting principle

Every deep puzzle is a tree of signals, not a bigger UI. Buttons are leaves. Intermediate gate outputs are named nodes (N1, N2…). The final LED is the only win light — but mid-LEDs (dim “probe lights”) can show whether a sub-puzzle is solved, without scoring.

Sub-puzzle

A known gate with a local goal. Its output becomes a wire into the parent gate.

Carry wire

Hot only when the sub-rule is true. Player sees it change color — same language as Track A.

Parent gate

Treats carry wires like buttons. Player must keep sub-conditions true while satisfying the outer rule.

Canonical pattern

Btn A→ GATE₁→ N1→ GATE₂→ LED
Btn B→ GATE₁ and/or Btn C→ GATE₂

Interaction stays: hold / toggle buttons only. No new gesture vocabulary. Challenge comes from which combination keeps N1 high while GATE₂ is happy.

Difficulty ladder

Tier What changes Player skill
0 Primer One gate, 1–2 buttons, one LED Map press → light
1 Chain Gate output feeds one other gate (depth 2) Hold a sub-condition while acting on the outer gate
2 Branch Two sub-gates feed one parent (fan-in) Coordinate two independent rules at once
3 Invert mid NOT on a carry wire; “wrong” feels right Reason about flipped intermediate state
4 Memory Latch / sticky node in the middle of a chain Set state, then solve the outer puzzle with hands free
5 Capstone Half-adder / mux / build-from-parts Recognize composed behavior as a named machine

Track B — Nest quests

Plan

Each quest below is one “page.” Depth increases; button count stays ≤ 3.

B1 · NOT into AND

Tier 1

Light the LED only when the red button is released and yellow is pressed.

Red→ NOT→ N1→ AND→ LED
Yellow→ AND
Win

LED on with red up + yellow down. If red is held, N1 dies and LED cannot stay on.

Why it teaches

First time a button’s “off” is useful. Player must read the mid-wire N1.

Prereq: A2 NOT, A4 AND

B2 · OR feeding AND

Tier 1

Either of two “door” buttons may arm the system; a third “key” must also be pressed.

Door1→ OR→ Armed→ AND→ LED
Door2→ OR Key→ AND
Win

Any door + key. Neither door alone. Key alone fails.

From concept: AND Handshake / real-world “door + key”. Prereq: A3, A4

B3 · XOR then OR

Tier 2

Exactly one of Red/Yellow creates “odd”. Blue is a bypass. LED on if odd or bypass.

Red→ XOR→ Odd→ OR→ LED
Yellow→ XOR Blue→ OR
Challenges

Both red+yellow → Odd=0; without Blue the LED dies. Player discovers “both cancels” then uses bypass.

From concept: XOR Door. Prereq: A5 XOR, A3 OR

B4 · Double NOT sandwich

Tier 1

Cover-page gag from the book: button → NOT → NOT → LED. Pressing lights it. Teaches cancellation.

Btn→ NOT→ N1→ NOT→ LED
Win

Hold button → LED on. Mid probe N1 is off while LED is on — important visual.

Book cover: two NOTs in series. Prereq: A2

B5 · AND of two NOTs (NOR-ish feel)

Tier 3

LED on only when neither button is pressed. Built as NOT(A) AND NOT(B) — no new gate name yet.

A→ NOT→ Ā→ AND→ LED
B→ NOT→ B̄→ AND
Win

Both released. Any press kills a mid-wire and the LED.

Reveal

After win: “You built a NOR.” Optional later page teaches NAND the same way: NOT(A AND B).

B6 · Branch: OR || AND into XOR

Tier 2–3

Left pair makes OR-result L. Right pair makes AND-result R. Final LED = L XOR R. Three or four buttons; prefer 3 by sharing one.

A→ OR→ L→ XOR→ LED
B→ OR B+ C→ AND→ R→ XOR
Design note

Shared B makes the truth table non-obvious. Goal copy: “Make L and R different.” Probe LEDs on L and R.

B7 · Broken jumper (spatial nest)

Tier 1

AND circuit with a gap on one input wire. Drag one jumper segment to close the path, then press both buttons.

Stages

1) Close the wire (N1 can go hot). 2) Satisfy AND. Nesting is physical path + logic rule.

Directly from concept.html “Broken Wire”.

Track C — Memory nests

Plan

Latch output becomes a sticky carry into another gate. Hands can leave SET and still keep a mid-signal high.

C1 · Latch Alarm + AND key

Tier 4
SET→ LATCH→ Q→ AND→ LED
RESET→ LATCH Key→ AND
Win sequence

1) Pulse SET (Q stays on). 2) Press Key → LED. 3) RESET clears for retry. Without SET first, Key alone fails.

Concept “Latch Alarm” composed with AND.

C2 · Armed XOR

Tier 4

Q from latch arms the board. Final LED = Q AND (A XOR B). Must arm, then choose exactly one of A/B.

Trap

Arming then pressing both A+B kills XOR. Player debugs with probe on Odd.

C3 · Build a Latch (compose)

Tier 5

Drag NOT / AND / OR tiles onto sockets until SET/RESET behavior matches the target demo LED.

Concept “Build a Latch” — book’s final-page idea. Unlock after C1–C2 so players know the behavior before assembling it.

Track D — Capstones

Plan

D1 · Half-Adder Spark

Tier 5

Two bits A,B. Sum LED = XOR. Carry LED = AND. Win when a given target pair lights (e.g. show 1+1 → Sum 0, Carry 1).

A→ XOR→ Sum
B→ AND→ Carry

From concept.html — first “math-like” machine.

D2 · 2-to-1 Mux

Tier 5

Select S chooses whether Data0 or Data1 reaches LED. Built as (D0 AND NOT S) OR (D1 AND S).

S→ NOT/ AND→ OR→ LED
Win

Match three target scenes: S=0 shows D0; S=1 shows D1; flip S live.

D3 · Parity lock

Tier 3

Three buttons into cascaded XORs. LED on for odd parity. Goal: light LED with exactly 1 or exactly 3 pressed.

D4 · Mystery Bus

Sandbox

Free place buttons/gates/LEDs. Optional “challenge cards” load a win condition into an empty board. Unlocked after D1.

Concept “Mystery Bus”.

Level data shape (for implementation)

One JSON-like object per quest. Evaluate bottom-up each frame.

{
  id: "b1-not-and",
  track: "B",
  tier: 1,
  prereq: ["not", "and"],
  buttons: [
    { id: "a", color: "red", label: "Red" },
    { id: "b", color: "yellow", label: "Yellow" }
  ],
  nodes: [
    { id: "n1", op: "NOT", inputs: ["a"], probe: true },
    { id: "out", op: "AND", inputs: ["n1", "b"], led: true }
  ],
  goal: "Release red, hold yellow.",
  completeWhen: { out: true, a: false, b: true },
  revealName: "NOT → AND"
}

Runtime rules

  • Buttons are boolean sources.
  • Nodes recompute each input change.
  • probe: true → small mid LED / hot wire label.
  • led: true → main win light.
  • Latch nodes keep state until RESET input.

Ship order (suggested)

  • 1. Graph evaluator + probe LEDs
  • 2. B1, B4, B2 (easiest nests)
  • 3. B3, B5, B6
  • 4. C1, C2 then C3 builder
  • 5. D1 half-adder, D2 mux
  • 6. B7 jumper + D4 sandbox
Keep copy literal: “Make the middle wire light, then the final light.” No timers. Wrong combos just leave the LED off. Hints point at a cold probe wire after idle — same as Track A.
